研究框架：分子、分母、水龙头

任何一个投资对象的价格 = 它未来赚的钱（分子）÷ 市场要求它给的回报（分母）；在中国市场，还要看谁在放水、谁在托底（水龙头）。

一个比喻

把价格想成一个水池的水位：分子是进水的多少，分母是池子的大小，水龙头是外面有没有人在额外加水或抽水。分子决定长期水位，分母决定同样多的水能撑多高，水龙头决定这几个月水位怎么晃。

三件事，每件事只问一个问题

分子

它未来赚的钱会变多还是变少？

由什么决定：销量 × 价格 × 利润率；最后看能否变成现金。

容易犯的错：看增速的方向（在加速还是减速），不只看高低；涨价带来的利润要分清是持续的还是一次性的。

分母

市场要求它给多高的回报？

由什么决定：无风险利率（A股看中国国债，港股看美国利率）＋ 风险溢价（政策、地缘、信用、情绪）。

容易犯的错：便宜不等于会涨；便宜只是下跌时的垫子，真正改变分母的是利率和风险事件。

水龙头

谁在买、谁在卖、谁在托底？

由什么决定：国家队与政策、杠杆资金、居民存款、外资与南向、新股与解禁供给。

容易犯的错：资金决定半年内的路径，不决定长期方向；资金流入不能再拿来证明盈利变好。

同一套问题，用在三个层级

横着看是同一层级的三件事，竖着看是同一件事在不同层级换了指标。

三层怎样接力

大盘 → 板块

大盘给出风向表；只研究自身三件事与风向同向的板块，逆风板块不进入优先研究。

→
板块 → 个股

板块的分子就是个股的蛋糕；个股只比较谁拿到的分子最多、最可靠。

→
个股 → 组合

分母与水龙头决定时机和仓位节奏，不重复给个股打分。

个股页现有三个决定与本框架一一对应：赛道归属＝板块是否顺风；兑现质量＝分子；价格反映＝分母与水龙头。

每一层都交付同样的六样东西

  1. 一句话结论（方向＋时机）
  2. 三件事各自的状态与证据
  3. 开关：要等什么外部条件
  4. 情景与概率：基准、上调、下调
  5. 跟踪单：定期看哪些指标、阈值是多少
  6. 证伪单：命题、现值、判定日、证实线、证伪线

持续更新：三类信息，三种处理方式

定期数据

按固定频率发布的数据：日度行情与资金、月度宏观、季度财报。

怎么处理：只更新现值；越过阈值才进入改判流程。不因为一天的涨跌改结论。

已排期事件

提前知道日期的会议和到期日：美联储议息、中央经济工作会议、两会、关税到期、财报截止。

怎么处理：事前写好预期，事后对照：符合预期不改，偏离预期按部件评估。

突发事件

事先不知道的冲击：地缘、政策突发、信用事件、监管变化。

怎么处理：先归类到三件事中的一个，再看是否触及阈值或直接回答某条证伪命题。

什么时候改结论

  1. 日度：只看是否触线；收盘连续3个交易日在线外才改判，单日触线只记录。
  2. 月度：每月15日左右（金融数据公布后）例行复核一次，更新现值，情景概率每次最多调整10个百分点。
  3. 排期事件：事件次日复核，对照事前预期。
  4. 突发事件：归类后观察3个交易日的价格与资金反应；有明确数字的政策（降息幅度、资金规模）可当日评估。
  5. 任何结论变化都要写进更新日志：哪个部件、哪条证据、原结论→新结论。

带走要点

  • 先问谁在决定价格：半年尺度上，分母和水龙头常常比分子更重要。
  • 大盘不选股，只给风向表；板块只研究顺风的，个股只比较谁拿到的分子最多。
  • 每个结论都要有跟踪单和证伪单；没有触线就不改结论。
