煤炭开采

更新 2026-11-11 · 判断窗口 2026-11-11 至 2027-05-11

未来半年的研究结论

煤炭保留主要研究方向，但应明确定位为盈利与现金回报验证：当前历史估值已偏高，不能再用“高股息且便宜”作为笼统结论。

证据支持什么判断

煤炭价格与三季度行业利润同比改善，冬季保供及合同稳定性提供支撑；同时非电需求偏弱、单季利润未持续环比上升。PE与PB处于较高历史分位，未来收益更依赖现金兑现，而非继续抬估值。

板块内部先研究什么

动力煤的长协现金流与现货弹性分开研究；焦煤需另看钢铁、地产和补库，不因为能源主线就一并升级。

为什么还不能作更强判断

完整行业自由现金流与2027盈利修订尚不足；高历史分位削弱了容错空间。

什么变化会让我改判

支持保持 / 升级：冬储后日耗和库存匹配，长协执行稳定；年度现金流扣除资本开支后仍覆盖分红，2027盈利预期保持。

触发下调：淡季库存累积、供给恢复压价或利润回落；分红依赖新增债务；估值维持高位而现金生成能力下降。

以上为基于已列资料的研究推断，研究顺序不代表收益排名。报告期和数据日期见下方节点表；证据缺口保留。

结论对应资料：国家统计局｜10月PPI · 国家发改委｜能源中长期合同管理办法解读 · 国金证券｜公用事业周报，11月8日 · 站内复算｜行业财务与交易指标，11月9日

逐节点分析

A · 需求

当前判断：冬季能源需求提供底部支撑，非电需求偏弱限制全面提价的持续性。

如何传到本板块

煤炭需求要分电力、钢铁、建材、化工。冬季取暖用煤有季节性支撑，但制造业新订单和建筑景气偏弱，不支持把动力煤与焦煤一起判断为需求强。煤价上涨也可能来自进口、供给或物流约束。

未来半年覆盖冬储结束和春季复工，重点不是把当前旺季价格外推六个月，而是看淡季电厂日耗、库存可用天数和非电开工能否承接。若电厂库存增加而日耗下降，现货支撑会变弱。

反证与解释边界

PPI为行业出厂价格加权指数，不能替代秦皇岛5500大卡现货，也不能直接用于计算每吨利润。

下一步如何验证行业判断

每周同步看电厂日耗、库存、港口库存、进口到岸价与长协价格；春节前后使用季节可比数据，避免把正常淡季下滑误判为周期反转。

B · 政策与地缘

当前判断：中长期合同规则强化履约和供给稳定，利润弹性取决于定价条款。

数据与证据

指标数值 / 事实日期口径 / 来源
能源中长期合同管理办法2026年第50号令；12月1日起实施2026-10-23公布覆盖煤炭、电力、天然气；不是一次性补贴
国家发改委｜能源中长期合同管理办法解读

如何传到本板块

规则加强中长期合同执行，有利于供需稳定和回款可预测性，但不承诺煤价或利润持续上涨。长协占比高能降低价格波动，现货占比高则更暴露于旺淡季切换。

能源安全同时鼓励有效供给，因而政策既支持保供，也可能抑制极端涨价。行业应追踪实际产量、进口和合同履约，不能把“保供”直接写成供给收缩。

反证与解释边界

政策目标是能源稳定，并非上市行业盈利最大化；煤炭与电力之间的利润分配可能改变。

下一步如何验证行业判断

12月执行后跟踪新年度合同定价和履约情况；若进口放量或供给恢复快于需求，降低对现货溢价的持续性判断。

如何传到本板块

27个可比样本收入、利润同比均改善，支持煤价通过C形成利润，但Q3利润环比小幅下降且仍有亏损样本，不能称全行业逐季加速。不同煤种、长协比例和成本结构导致盈利分化。

“现金回报”需要经营现金减维持性资本开支后仍能覆盖分红。高会计利润若用于扩产、并购或增加应收，并不能同额分配。本轮财务聚合尚未给出完整自由现金流，因此主线依据是盈利改善与保供属性，不是已确认的股息保证。

反证与解释边界

单季度同比不能排除低基数；PPI涨幅也不能直接乘以收入推算净利润。

下一步如何验证行业判断

年报将行业经营现金、资本开支、债务和分红放在同一张表；若分红由加杠杆支撑，应降低“现金回报”判断。

如何传到本板块

煤价上行通过C提高现金生成，但国内低利率只增加稳定现金回报的相对吸引力，不能抵消高估值与煤价回落。估值应以跨周期现金流折现，不能用旺季利润永久化。

用“盈利不变、估值倍数下降”的压力情景检验安全边际。如果半年盈利提高20%、倍数下降20%，两者相乘仍对应价格约下降4%；增长本身并不保证价格上涨。

反证与解释边界

这里的20%是敏感性演示，不是对收益或估值的预测。不能用政策利率直接扣减PE倒数计算股票风险溢价。

下一步如何验证行业判断

每次议息后更新政策预期，每周比较长端利率、信用利差；港股同时查看HIBOR及汇率，再判断D→F/G的方向。

如何传到本板块

半年预测应拆为冬季价格、春季销量、长协重定价和成本。若市场已按冬季高价给出全年利润，春季回归正常就可能触发E下修，即使利润仍高于去年。

因此要比较2027预测采用的煤价假设，而不是只看预测净利润增速。低成本与稳定合同可缓冲下行，但行业合计中现货和焦煤暴露会增加波动。

反证与解释边界

缺少一致预期序列时不能声称机构已普遍上调。

下一步如何验证行业判断

每月记录煤价、销量、成本假设及2027行业利润预测，重点检查冬季后盈利预期是否保持。

未来半年：基准与改判情景

以下是研究判断条件，不是概率预测或收益承诺。

情景条件与判断研究应如何调整
基准判断煤炭保留主要研究方向，但应明确定位为盈利与现金回报验证：当前历史估值已偏高，不能再用“高股息且便宜”作为笼统结论。动力煤的长协现金流与现货弹性分开研究；焦煤需另看钢铁、地产和补库，不因为能源主线就一并升级。
转强 / 升级冬储后日耗和库存匹配，长协执行稳定；年度现金流扣除资本开支后仍覆盖分红，2027盈利预期保持。先确认A/B已传到C，再看E修订及F是否合理；G/H提供市场确认，不单独触发经营结论。
转弱 / 降级淡季库存累积、供给恢复压价或利润回落；分红依赖新增债务；估值维持高位而现金生成能力下降。回到出现反证的具体节点调整半年判断；不因原来列为主要方向而维持旧结论。

未来半年如何跟踪

保持 / 升级条件

冬储后日耗和库存匹配，长协执行稳定；年度现金流扣除资本开支后仍覆盖分红，2027盈利预期保持。
