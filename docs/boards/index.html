主要方向 · 2 个方向

煤炭开采

煤炭保留主要研究方向，但应明确定位为盈利与现金回报验证：当前历史估值已偏高，不能再用“高股息且便宜”作为笼统结论。

为什么这样判断：煤炭价格与三季度行业利润同比改善，冬季保供及合同稳定性提供支撑；同时非电需求偏弱、单季利润未持续环比上升。PE与PB处于较高历史分位，未来收益更依赖现金兑现，而非继续抬估值。

板块内如何取舍：动力煤的长协现金流与现货弹性分开研究；焦煤需另看钢铁、地产和补库，不因为能源主线就一并升级。

估值核验：煤炭当前并非历史低估值板块。高现金回报逻辑需要以未来可分配现金支撑，不能再叠加“便宜”的默认前提；盈利回落时低PE幻觉与估值收缩可能叠加。

冬储支撑，非电需求弱 → 利润同比好，现金需覆盖 → PE/PB历史分位偏高

航运港口（偏油运）

油运保留主要研究方向，但当前属于高盈利、高地缘波动阶段；半年判断应以运价正常化后仍能保留多少利润为核心。

为什么这样判断：航线租金仍高，但美湾与中东航线已出现不同幅度回落，短租和长租报价差距也提示当前景气不能永久外推。运输量、航程与有效船队共同决定盈利，油价本身不能替代这套判断。

板块内如何取舍：分别研究原油油轮与成品油轮、不同航线和租约期限；关注吨海里、可运营天数与成本后的净租金，不把整个航运行业合并。

估值核验：本轮只能明确检验正常化盈利，无法可靠宣称处于历史估值底部。用当前高租金计算的低PE可能高估便宜程度，需并看船舶净资产与资本开支。

吨海里与有效运输量 → 实现TCE×营运天数 → 船舶资产与周期现金流

验证重点：每周更新产品/订单、价格与交易；月度更新行业供需和政策执行；季报核利润与现金；年报后复核2027预期。数据日期分别标注，不把11月9日行情写成11月11日。

条件看好 · 6 个方向

半导体

未来半年仍条件看好AI服务器相关的存储、互联与先进封装；目前更像需求强、估值与价格仍在消化的结构性阶段，不能把整个半导体认定为低估反转。

为什么这样判断：需求端有实际AI基础设施支出和国内产量增长支撑；但产业内部消费需求、供给瓶颈和利润分布差异明显。五年PE分位偏低与PB、PS偏高并存，说明此前热度的消化并不等于所有估值维度已便宜。价格验证仍偏弱，应把“经营值得继续研究”与“市场趋势已确认”分开。

板块内如何取舍：先研究AI新增需求对应的高带宽存储、互联与封装，再研究设备材料的真实采购兑现；成熟制程、模拟功率与消费链单独看库存和利用率，不能共享AI结论。

估值核验：PE已到五年偏低位置，但PB中位偏上、PS仍高；市场可能在给当前较高利润率定价。不能用PE单指标宣布“历史底部”。若盈利回落20%而价格不变，52.98倍PE会升至约66.23倍。

AI支出强，消费链分化 → 利润集中，现金待验证 → PE低分位，PB/PS仍高

验证重点：每周更新产品/订单、价格与交易；月度更新行业供需和政策执行；季报核利润与现金；年报后复核2027预期。数据日期分别标注，不把11月9日行情写成11月11日。

计算机设备

未来半年条件看好服务器及配套设备，重点是实际交付和单位毛利；全行业仍不能用“AI高增长”统一定价。

为什么这样判断：全球服务器金额与台数都增长，但价格及高配置贡献显著。国内计算机设备财报同比改善，单季利润环比下降且亏损面不小，需求传到现金收益的链条还不完整。

板块内如何取舍：区分AI服务器、通用服务器、网络存储配套与办公终端；优先研究订单可验收、供应链可交付、成本可转嫁的细分环节。

估值核验：只有两个估值截面不足以确定历史便宜程度。利润高度波动时，要用正常交付和正常毛利率下的盈利作压力测试；不能因PE比去年低就判定低估。

服务器台数与配置双驱动 → 单位毛利和应收库存 → 缺历史分位，核正常毛利

化学制药（创新药）

未来半年条件看好创新药商业化与支付扩容，但优先验证持续销售和现金；授权新闻与一次性利润不足以支持整个板块升级。

为什么这样判断：创新平台样本收入和利润增长支持产业进展，医保及商保提供准入路径；与此同时医药价格仍有压力，宽化学制药PE未处于极低历史位置。

板块内如何取舍：区分已商业化创新药、海外授权与研发阶段；分别用持续销售、到账现金与临床成功概率评价，避免用同一PE套全部项目。

估值核验：宽口径PE在历史中位附近，PB较低，不能笼统说创新药估值低。研发期资产用PE不适合，应按成功概率和现金消耗比较；商业化部分才适合正常盈利估值。

化学原料

未来半年条件看好价差修复和供给约束清晰的细分化工，当前不支持全板块普涨判断。

为什么这样判断：行业利润同比改善但环比承压，周度产品价格涨跌分化，部分涨价产品仍亏损。宽行业估值处于历史中低位置，提供一定研究空间，但需要真实价差和现金流兑现。

板块内如何取舍：按终端需求与原料路线区分；优先跟踪库存下降、价差改善且净新增产能有限的产品，新材料另看认证放量。

估值核验：宽行业处于中低区间而非极端便宜。长历史包含不同供给、行业结构与盈利周期；若周期利润正在高位，PE中低不保证安全边际。

产品分化，非全面复苏 → 售价减原料能源成本 → 宽行业中低，非极低

工业金属（偏铜）

未来半年条件看好铜的结构性需求与矿端供给约束，但暂不把铜判为确定性短缺主线；矿山与冶炼必须分开。

为什么这样判断：电网和AI需求提供支撑，矿山增速预测被下调；同时ICSG仍预测2027精铜过剩扩大。支持的是矿端约束和局部机会，不是总需求压倒供给的单边判断。

板块内如何取舍：先研究矿端成本与产量弹性，再单独验证冶炼加工费；铜加工看终端订单和现金周转。

估值核验：宽金属PE下降包含利润周期与样本影响。铜矿应用正常化铜价下的现金流和储量成本检验，冶炼看加工费与资本回报；一个低PE不能把两者同时判为便宜。

电网设备

未来半年条件看好电网结构性建设，电表与特高压证据强于普遍输变电扩张；估值需要订单兑现支撑。

为什么这样判断：电网完成投资增长，但前五批输变电设备招标金额下降；电表与特高压呈现更强的细分需求。说明总量背景成立，受益环节和时间仍需要筛选。

板块内如何取舍：分别研究特高压、配网及电表更新、变压器等出口需求；用项目招标和交期验证AI用电叙事。

估值核验：29.47倍本身不能判定贵或便宜。必须核验订单增长、毛利与现金回收是否支持盈利持续增长；当前历史分位不完整，暂不给“低位”标签。

总投资与招标结构分化 → 材料、交付、验收回款 → 当前PE有值，分位未齐
