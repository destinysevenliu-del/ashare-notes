主要方向 · 2 个方向

煤炭开采

未来半年仍把煤炭放在现金回报方向。逻辑来自供需相对成熟、长协与成本结构对经营波动的缓冲；它要求价格回落后行业仍有可分配现金，并不以煤价持续上行为前提。

为什么这样判断：判断沿A/B→C→E/F展开：先看电力耗煤、非电用煤与港口库存，再看保供、安全生产、进口与长协定价如何改变供需或成本，最终落到销量×实现煤价−开采运输成本。这是一条需逐环验证的行业推导；宏观支持只能证明背景，不能独自证明行业利润转强。

板块内如何取舍：动力煤与焦煤分别跟踪；长协和现货分别观察。比较重点是各细分环节的需求弹性、供给扩张速度、成本转嫁能力与资本开支回收期；先区分利润来源，再判断哪些方向具有更强持续性。

A/B → C → E/F
电力耗煤、煤炭库存 → 煤价×销量−开采成本 → 行业盈利与资本回报

验证重点：按月跟踪电力耗煤、非电用煤与港口库存；季度核行业利润率、库存/应收、资本开支与现金流。

航运港口（偏油运）

油运保留盈利弹性方向。有效运力紧张与运输距离增加可以抬高运价，但必须仍有货可运、船可营运。未来半年最重要的分歧是运输约束带来的吨海里增量，能否超过贸易收缩和营运受阻造成的损失。

为什么这样判断：判断沿A/B→C→E/F展开：先看原油和成品油贸易量、吨海里与有效船队供给，再看航路安全、制裁、保险和船舶环保约束如何改变供需或成本，最终落到同船型航线TCE×有效营运船天−营运及融资成本。这是一条需逐环验证的行业推导；宏观支持只能证明背景，不能独自证明行业利润转强。

板块内如何取舍：原油轮、成品油轮与LNG运输分别研究；集运和港口不纳入油运判断。比较重点是各细分环节的需求弹性、供给扩张速度、成本转嫁能力与资本开支回收期；先区分利润来源，再判断哪些方向具有更强持续性。

A/B → C → E/F
原油货量、绕航吨海里 → TCE×营运船天−成本 → 行业盈利与资本回报

验证重点：按月跟踪原油和成品油贸易量、吨海里与有效船队供给；季度核行业利润率、库存/应收、资本开支与现金流。

条件看好 · 6 个方向

半导体

未来半年条件看好半导体的结构性需求。互连受内存升级和单机价值变化影响，封测受先进封装订单与稼动率影响，存储受供给缺口、库存与涨价周期影响。这些因素可能不同步，因此不能给整个半导体行业一个统一的增长假设。

为什么这样判断：10月计算机通信电子设备制造业生产与新订单指数均在53及以上，支持电子产业需求强于制造业总量的判断，但这一口径比半导体更宽。因而半年判断保留结构性机会：互连看内存升级带来的单机价值与渗透，封测看技术复杂度与稼动率，存储看供需和库存；不能用电子行业PMI证明三条线均已兑现。

板块内如何取舍：互连芯片、先进封测和存储分开；通用消费芯片不能自动分享同一景气。比较重点是各细分环节的需求弹性、供给扩张速度、成本转嫁能力与资本开支回收期；先区分利润来源，再判断哪些方向具有更强持续性。

A/B → C → E/F
服务器内存升级与出货 → 接口芯片结构／封测稼动 → 行业盈利与资本回报

验证重点：按月跟踪服务器内存升级、先进封装需求、存储供需与终端库存；季度核行业利润率、库存/应收、资本开支与现金流。

计算机设备

算力设备维持条件看好。行业资本开支扩张只有转成采购、交付和验收，才形成设备收入；产品竞争和营运资金占用又决定收入能留下多少利润。未来半年的核心是投资规模与产业链回报是否同步，而不是建设项目数量。

为什么这样判断：判断沿A/B→C→E/F展开：先看云、运营商与政企算力采购，服务器及网络设备更新，再看算力基础设施、技改、采购规则与关键部件供应约束如何改变供需或成本，最终落到设备交付额×毛利率−费用减值；再核库存应收占用。这是一条需逐环验证的行业推导；宏观支持只能证明背景，不能独自证明行业利润转强。

板块内如何取舍：服务器制造、网络设备与项目集成分开，安全软件属于相邻需求。比较重点是各细分环节的需求弹性、供给扩张速度、成本转嫁能力与资本开支回收期；先区分利润来源，再判断哪些方向具有更强持续性。

A/B → C → E/F
云厂商、运营商、政企 → 交付量×售价×毛利 → 行业盈利与资本回报

验证重点：按月跟踪云、运营商与政企算力采购，服务器及网络设备更新；季度核行业利润率、库存/应收、资本开支与现金流。

化学制药（创新药）

创新药维持条件看好，重点看商业化渗透和许可兑现能否形成持续行业盈利。临床进展可以改变未来市场空间，但从试验到审批、支付、销售存在时滞；半年判断要区分已发生销售与尚有条件的远期收入。

为什么这样判断：判断沿A/B→C→E/F展开：先看患者覆盖、适应症、医保可及性与商业化销量，再看临床审批、医保谈判、集采与跨境许可监管如何改变供需或成本，最终落到持续药品销售毛利＋已确认许可收益−研发及销售费用。这是一条需逐环验证的行业推导；宏观支持只能证明背景，不能独自证明行业利润转强。

板块内如何取舍：商业化创新药、临床管线、许可交易和成熟仿制药分开。比较重点是各细分环节的需求弹性、供给扩张速度、成本转嫁能力与资本开支回收期；先区分利润来源，再判断哪些方向具有更强持续性。

A/B → C → E/F
患者、适应症与可及性 → 持续销售＋已确认许可 → 行业盈利与资本回报

验证重点：按月跟踪患者覆盖、适应症、医保可及性与商业化销量；季度核行业利润率、库存/应收、资本开支与现金流。

化学原料

化学原料保留条件看好，判断对象是具体产品和生产路线的价差修复。PPI上涨只说明价格背景，既可能提高产品售价，也可能加重原料负担；只有库存、开工和价差共同改善，才支持把利润修复延伸到未来半年。

为什么这样判断：判断沿A/B→C→E/F展开：先看下游开工、产品库存、新产能投放与原料供给，再看原料进口、能耗环保、运输与出口安排如何改变供需或成本，最终落到销量×产品减原料价差−加工费用及折旧。这是一条需逐环验证的行业推导；宏观支持只能证明背景，不能独自证明行业利润转强。

板块内如何取舍：轻烃、煤制烯烃、聚氨酯、纯碱等路线各算价差。比较重点是各细分环节的需求弹性、供给扩张速度、成本转嫁能力与资本开支回收期；先区分利润来源，再判断哪些方向具有更强持续性。

A/B → C → E/F
聚烯烃需求、下游开工 → 销量×产品减原料价差 → 行业盈利与资本回报

验证重点：按月跟踪下游开工、产品库存、新产能投放与原料供给；季度核行业利润率、库存/应收、资本开支与现金流。

工业金属（偏铜）

铜的结构需求逻辑保留，但仍为条件看好。电网等投资可以增加需求，行业实际强弱还要经过库存和供给验证；矿山受益于铜价，冶炼利润却可能受加工费挤压，所以不能把铜价上涨解释为全产业链共同受益。

为什么这样判断：判断沿A/B→C→E/F展开：先看电网、制造业用铜、可见库存和矿山供给，再看矿权、资源国税费、环保与跨境贸易规则如何改变供需或成本，最终落到矿山看铜价×权益产量−现金成本；冶炼看加工费与副产品收益。这是一条需逐环验证的行业推导；宏观支持只能证明背景，不能独自证明行业利润转强。

板块内如何取舍：铜矿、冶炼和加工分开；金、钴等不能并作纯铜驱动。比较重点是各细分环节的需求弹性、供给扩张速度、成本转嫁能力与资本开支回收期；先区分利润来源，再判断哪些方向具有更强持续性。

A/B → C → E/F
电网等终端需求与库存 → 铜价×产销量−现金成本 → 行业盈利与资本回报

验证重点：按月跟踪电网、制造业用铜、可见库存和矿山供给；季度核行业利润率、库存/应收、资本开支与现金流。

电网设备

电网设备是政策到需求路径较清楚的条件方向。政策改善项目资金和启动条件，招标、制造、交付、验收才把投资转成行业收入；未来半年应观察项目执行强度与回款，而不是直接把规划金额当利润。

为什么这样判断：判断沿A/B→C→E/F展开：先看电网招标规模、建设进度、交付验收与更新需求，再看新型电网规划、特高压项目、融资支持与招标规则如何改变供需或成本，最终落到订单转交付×设备毛利率−费用减值；回款决定现金兑现。这是一条需逐环验证的行业推导；宏观支持只能证明背景，不能独自证明行业利润转强。

板块内如何取舍：自动化保护、直流输电、高压开关与配网设备分开。比较重点是各细分环节的需求弹性、供给扩张速度、成本转嫁能力与资本开支回收期；先区分利润来源，再判断哪些方向具有更强持续性。

A/B → C → E/F
电网招标、项目开工 → 交付额×毛利−费用减值 → 行业盈利与资本回报

验证重点：按月跟踪电网招标规模、建设进度、交付验收与更新需求；季度核行业利润率、库存/应收、资本开支与现金流。
