研究汇总

宏观重构后（11月13日）：A股未来半年是托底下的存量震荡与风格再平衡。电网设备维持结构性看好并看2027年一季度订单；半导体维持结构性看好、计算机设备维持条件看好，但都受美国利率开关约束、反弹不追；煤炭、油运属窗口前半段配置，PPI见顶即降级；化工从反内卷角度细分观察；创新药条件看好但美国加息期估值受压。

大盘层面，分子（企业盈利）的改善集中在上游涨价与AI出口，PPI同比预计11月—1月见顶；分母（要求回报）上，中国利率下行而美国利率仍在抬升；水龙头（资金与托底）上，国家队托底大盘股，但没有存款搬家。因此板块取舍按“顺风、前半段、等开关”三档处理，而不是按单一景气排序。

当前研究重心

先看托底与高股息、政策投资链；上游资源只做前半段；AI硬件等美国利率开关。宏观依据与可证伪清单见首页。

相较上一轮的变化

11月13日：按“分子、分母、水龙头”框架重写大盘判断；板块分组不变，新增时机约束与降级条件。银行、保险高股息与反内卷行业列为新增观察，尚未建立板块研究。
