主要方向 · 3 个方向

电信等现金流型业务

电信保留现金回报方向，依据是基础通信的持续服务需求，而不是预设行业高增长。未来半年必须同时考察服务收入、资本开支与现金留存：若新投入持续压缩自由现金流，传统的防守属性也会减弱。

为什么这样判断：判断沿A/B→C→E/F展开：先看通信用户、ARPU、服务使用量与云网需求，再看资费监管、频谱安排、共建共享与算力投资要求如何改变供需或成本，最终落到服务收入−运营费用；经营现金流减资本开支检验分红基础。这是一条需逐环验证的行业推导；宏观支持只能证明背景，不能独自证明行业利润转强。

板块内如何取舍：基础通信、云服务和基础设施租赁分开。比较重点是各细分环节的需求弹性、供给扩张速度、成本转嫁能力与资本开支回收期；先区分利润来源，再判断哪些方向具有更强持续性。

A/B → C → E/F
通信服务、用户与ARPU → 服务收入−运营成本 → 行业盈利与资本回报

验证重点：按月跟踪通信用户、ARPU、服务使用量与云网需求；季度核行业利润率、库存/应收、资本开支与现金流。

能源生产

能源保留油气盈利弹性和煤炭现金回报两条方向。供给约束能支持产品价格，但供应恢复会改变半年利润假设；上游生产、炼化和煤炭的成本与售价传导不同，行业判断应按子链条分别成立。

为什么这样判断：判断沿A/B→C→E/F展开：先看油气和煤炭供需、库存、产量与实现价格，再看资源开发、保供长协、制裁与供应恢复安排如何改变供需或成本，最终落到资源价格×产销量−开采成本；扣资本开支后评价现金回报。这是一条需逐环验证的行业推导；宏观支持只能证明背景，不能独自证明行业利润转强。

板块内如何取舍：油气上游、炼化、煤炭和煤电一体化分开。比较重点是各细分环节的需求弹性、供给扩张速度、成本转嫁能力与资本开支回收期；先区分利润来源，再判断哪些方向具有更强持续性。

A/B → C → E/F
油气供需、煤炭需求 → 油气量价成本／煤电运 → 行业盈利与资本回报

验证重点：按月跟踪油气和煤炭供需、库存、产量与实现价格；季度核行业利润率、库存/应收、资本开支与现金流。

油运

港股油运保留盈利弹性方向，行业逻辑仍是货量、航程和有效运力的相互作用。上市市场不会改变油运经营机制，但港元融资、流动性和风险溢价会影响同一行业逻辑能获得多高估值。

为什么这样判断：判断沿A/B→C→E/F展开：先看原油贸易量、吨海里、船队交付与实际可用运力，再看航路安全、制裁、保险与航运环保约束如何改变供需或成本，最终落到TCE×有效船天−燃料、保险、租赁和融资成本。这是一条需逐环验证的行业推导；宏观支持只能证明背景，不能独自证明行业利润转强。

板块内如何取舍：原油轮、成品油轮与LNG运输分开，港股定价约束单独看。比较重点是各细分环节的需求弹性、供给扩张速度、成本转嫁能力与资本开支回收期；先区分利润来源，再判断哪些方向具有更强持续性。

A/B → C → E/F
原油运输量、吨海里 → TCE×营运船天−成本 → 行业盈利与资本回报

验证重点：按月跟踪原油贸易量、吨海里、船队交付与实际可用运力；季度核行业利润率、库存/应收、资本开支与现金流。

条件看好 · 2 个方向

互联网平台与软件服务

互联网维持条件看好，判断重点是不同商业模式的需求和投入产出差异。广告受营销预算和转化效率影响，电商受消费与竞争影响，云和AI受算力需求及资本开支影响；行业收入增长与利润增长可能不同步。

为什么这样判断：行业利润取决于需求增长与投入强度的差额。广告转化改善可以提高变现效率，电商交易增长却可能伴随补贴和履约费用上升，云需求增长也可能伴随算力投资与折旧扩张。因此A的改善必须经C验证，不能把AI投入规模本身记作盈利利好。

板块内如何取舍：广告与内容、电商与本地生活、云与AI服务分开。比较重点是各细分环节的需求弹性、供给扩张速度、成本转嫁能力与资本开支回收期；先区分利润来源，再判断哪些方向具有更强持续性。

A/B → C → E/F
广告、游戏、电商、云 → 收入×利润率−费用折旧 → 行业盈利与资本回报

验证重点：按月跟踪广告预算、游戏付费、电商交易与企业云需求；季度核行业利润率、库存/应收、资本开支与现金流。

半导体及算力相关硬件

港股半导体和算力硬件维持条件看好，行业内部必须按代工、设备、整机拆开。设备订单上升可能领先产能投放，新增产能又可能先增加折旧再形成利润；同一轮算力建设不会让所有环节同时受益。

为什么这样判断：判断沿A/B→C→E/F展开：先看晶圆出货、先进封装扩产与服务器整机需求，再看设备出口限制、供应保障与产业投资支持如何改变供需或成本，最终落到代工看利用率售价和折旧，设备看订单交付，整机看毛利回款。这是一条需逐环验证的行业推导；宏观支持只能证明背景，不能独自证明行业利润转强。

板块内如何取舍：晶圆代工、封装设备与整机基础设施分开。比较重点是各细分环节的需求弹性、供给扩张速度、成本转嫁能力与资本开支回收期；先区分利润来源，再判断哪些方向具有更强持续性。

A/B → C → E/F
晶圆客户出货、硬件需求 → 代工稼动率×售价−折旧 → 行业盈利与资本回报

验证重点：按月跟踪晶圆出货、先进封装扩产与服务器整机需求；季度核行业利润率、库存/应收、资本开支与现金流。
