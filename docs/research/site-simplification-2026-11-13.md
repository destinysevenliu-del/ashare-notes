# 2026-11-13 全站精简与个股三维决策（当前有效）

- 主导航只保留「总览 / 板块 / 个股」；A股与港股在总览、板块内切换。报告、操作记录、筛选规则、组合约束降为辅助入口。
- 默认先看结论、关键证据、改判条件；A–H传导图与详细证据按需展开。保留原研究资料与历史报表，不用生成日期伪装新行情。
- 宏观唯一当前摘要：`data/market_thesis.json` 的 `macro_overview` / `macro_nodes`，由 `pipeline/overview_page.py` 渲染。只输出盈利、估值与D/G组合约束；具体板块结论由 `industry_research.json` 独立维护。旧跨层完整研究作为11月12日留档，不能重新渲染成现行首页。
- 宏观图是研究顺序，不宣称世界只有单向因果：B→A/C/D、A→C/D、C→E、E/D→F、E/F/G→H；H→G虚线只进入下一期。F是估值约束与重估空间，不能用当前PE循环解释当前价格；E为未来盈利预期，一致预期是可观测证据，不是唯一合法预期。
- 个股入口：`pipeline/stockpage.py` 只调用 `stock_decisions.py`，旧个股A–H加总打分退出当前构建。个股三个决策为：赛道归属（入池门）、兑现质量（排序）、价格反映（时机）。
- A/B/C只判是/否；材料未核齐展示待核，不自动入池。兑现质量使用同一发行人同一TTM正常化财务包；同理由仅一个主排序指标。现金、毛利、应收、库存和固定2027同机构盈利修订只验证/否决，不叠加加分。
- 每板块一个主估值：周期PB，成长PS或正常化PE。辅助估值只否决；主指标区间必须有事先登记的依据和有效期。当前95%辅助分位否决是首版可调研究规则，未经回测；不解释为已验证买卖阈值。
- D/G只在组合层控制仓位与节奏；H只作执行验证，不逆向增加兑现排名。同一事实ID不能跨职能重复使用。
- 配置：`data/stock_selection_policy.json`；审核：`data/stock_decision_reviews.json`。后者目前无已核审查记录：61条原候选资料保留但不自动通过新入池门。历史20股配置是抓取/留档来源，不是现行20只推荐名单。
- 收敛最多10家发行人：不同理由分子池独立排序；同公司A/H共用财务；跨子池须指定唯一主子池；边界并列留待复核；不凑数、不全局打分。当前9个分配研究席位+1个预留为可调研究容量设置，不是投资权重或已选名单。国资/小盘/箱体策略未自动激活，不混入需求兑现池。
- 公共结果：`docs/data/stock_decisions.json`；入口：`docs/stocks/index.html`；规则与组合分别位于 `selection-rules.html`、`portfolio.html`。
