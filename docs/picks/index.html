组合级风控

这些是硬规则，触发就执行，不在盘中重新讨论。

  1. 总仓位 55%，不满仓。沪深 300 跌破 250 日线 → 降到 40%。
  2. 单只 ≤ 4%，单板块 ≤ 12%，C 档（高波）合计 ≤ 14%。
  3. 单只回撤 -15% 触发复核；-25% 强制减半。
  4. 组合回撤 -10% → 停止加仓，先诊断是哪一层错了。
  5. PPI 同比连续 2 个月回落 → 资源仓从 26% 降到 15%。
  6. 每月 1 号复核；每季报后 3 日重跑四道门；证伪条件触发当天移出。

怎么读这一页

这一页是决策记录，不是行情页。它回答的是“我为什么买、什么情况下我错了”，所以数字固定在 2026-11-09，只在季报后重算。 想看今天发生了什么，回大盘页、板块页或个股页。 页面只呈现假设与条件，不构成投资建议；仓位是风险预算上限，不是推荐买入。

数据来自东方财富、中证指数公司的公开数据，外部环境和政策为人工整理。判定规则版本 2026-11-10 v3（新增全球环境、实际利率、杠杆拥挤度、盈利分位），每节的“怎么判的”里有完整规则。
