计算机设备 · 股票研究

此页按三个决策维度组织待选池：赛道归属（入池门）→ 兑现质量（池内排序）→ 价格反映（时机）；利率与资金约束上移到组合层。尚未确定买入个股。行业判断请返回独立板块分析。

本池筛选规则：节点先分工，再筛选

收敛规则一 · 职能分离：A/B/C 只回答"是否入池"，不打分；C→E 用同一套财务口径决定池内优先级；F 只保留一个主估值指标决定时机；D、G 属于组合层，约束仓位与节奏，不在本页对个股加减分。

收敛规则二 · 理由唯一：入池必须先回答"当前半年这个方向只接受哪一类理由"；理由类型不同的公司分入不同子池，不合并排序。

收敛规则三 · 不重复加权：同一份营收、同一份现金流、同一份估值分位，不在多个节点重复计分。

A–H 节点在个股筛选层的职能

框架节点在个股筛选层的职能职能边界（不做什么）
A · 需求入池门只回答"业务连接是否成立"，是/否判定，不打分
B · 政策与地缘入池门只回答"政策或事件是否支持这条业务连接"，不打分
C · 行业利润与现金流入池门 + 兑现质量入池时核验业务连接；池内排序时与 E 共用同一套财务口径
D · 利率与风险溢价组合层决定整体仓位上限与折现假设，不对个股单独加减分
E · 盈利预期修订兑现质量作为 C 口径的修正提醒，不与 C 重复加权
F · 估值时机一个主估值指标决定现在追 / 等 / 不追，其余指标只作否决
G · 资金与拥挤度组合层决定加仓节奏与拥挤度预警，不对个股单独加减分
H · 价格验证时机价格是否确认逻辑，与 F 同属时机维度

维度一 · 赛道归属：入池门（A/B/C 是/否判定）

当前半年（2026-11-11 至 2027-05-11）本板块只接受一类入池理由：

订单兑现：从算力订单到毛利和回款的转化

板块结论的条件看好取决于订单 → 毛利 → 回款转化能否核验；收入规模本身、「AI 服务器」概念、低估值都不构成本板块的入池理由。

入池门规则：A 算力订单与中标公告、B 政策与供应链、C 收入-毛利-回款连接：订单与交付可核验 → 入池；只有收入、没有毛利与回款数据 → 退回观察。只做是/否判定，不打分。

下表只做是/否判定：业务连接成立且已核 → 是；连接 plausible 但业务占比未核验 → 待核；触发淘汰条件 → 退回观察或出池。待选不等于已选。

维度二 · 兑现质量：池内排序（C→E 一套财务口径）

池内排序只用一套转化口径：订单 → 收入增速 → 毛利率 → 回款（应收增速与经营现金流）。E 盈利修订作为同口径修正；收入规模单独不构成排序优势。

排序依据与 A/B 入池判定不叠加；E 盈利修订是 C 口径的修正，不再单独加权。各子池只在池内排序，跨池不合并名次。

维度三 · 价格反映：时机（F 主指标 + 否决条件）

本板块唯一主估值指标：PS（收入口径）

整机与数字基础设施毛利低、净利波动大，主指标取 PS；PS 与 PE 不并列排序。

其余估值指标一律降为否决条件，不参与排序，只在触发阈值时把候选降级：

  • 毛利率低于可比或同比下滑超过 2 个百分点：降级复核
  • 应收增速显著超收入增速（回款恶化）：否决
  • PE 极低或极高只作否决提示，不参与排序

订单-回款转化在验证且 PS 未触发否决 → 分批；转化成立但 PS 已高 → 等待；回款恶化 → 不追。

估值分位与价格位置数据见各板块页「数据现状与估值位置」；个股的 PE/PB 与价格通道在个股页「股价层」，两处数据同源，不在本页重复计分。H 价格验证与 F 同属时机维度：价格没有确认逻辑之前，排序靠前也不构成买入理由。

组合层约束：D 利率与 G 资金不在本页计分

D（利率与风险溢价）与 G（资金与拥挤度）已上移到组合层：D 决定整体仓位上限与折现假设，G 决定加仓节奏与拥挤度预警。它们约束"买多少、多快买"，不对任何个股单独加减分，也不与本页三个维度并列排序。

个股页保留的融资余额、股东户数等数据仅作组合层参考的展示，不进入个股合计分。

龙头与细分标杆观察（行业动向参考，不参与排序）

先观察行业龙头，再筛选合适个股。观察身份按主营业务和行业代表性确定，不作市值或市占率排名；最终可以选择龙头，也可以选择其他公司。龙头观察只提供 A/B/C 入池门与行业动向的对标素材，不因其龙头身份在维度二、三获得任何加分。A/H 同一发行人的经营证据复用，估值和交易信号分别处理。
