价格规则：买入价、卖出价、止损价怎么算

本页所有价格都按下面的规则计算。规则写在这里，以后跟进时按同一套口径重算，不凭当时的感觉调。

一、四类板块各用一套规则

板块类型买入卖出止损为什么这样定
顺风但拥挤银行每股分红÷(10年国债+2.5%)，向下留3%作为区间每股分红÷(10年国债+2.0%)不设价格止损；分红下调、或10年国债持续高于1.85%时退出买银行买的是分红，价格高低只体现在“股息率比国债高多少”。卖出线2.0个百分点与板块页的降级线是同一条线，个股和板块用同一把尺子。银行波动小，价格止损容易被噪音打掉，所以改用基本面退出条件。
看价格水平（前半段）煤炭、石油、油运一年区间位置0.2—0.4，且上沿不高于60日均线区间位置0.9（接近一年高点）一年低点下方5%“前半段”的意思是顺风只持续到PPI同比的平台期（约到2027年2月数据），3—4月数据会机械回落。所以只做区间内的往返，不假设创新高；买点放在区间下部、不追到均线上方；跌破一年低点说明价格水平的判断错了。
等开关半导体、算力硬件、创新药开关打开、且价格先站上60日均线之后：60日均线至均线上方5%第一目标取“一年区间中位”与“买入区中点+2倍风险距离”中较高者；第二目标为一年高点下方5%买入区中点下方12%与一年低点下方5%中较高者开关打开前不买，价格在区间里再低也不买。站上60日均线是开关②的价格条件，买点限定在均线上方5%以内，防止追高。目标至少是风险的两倍，否则这笔交易不值得做。
看成本与价差电网设备、化工一年区间位置0.15—0.35区间位置0.8一年低点下方5%逻辑是成本下降或价差修复带来的毛利改善，兑现慢、没有强催化，所以买得比上游更低、卖得比上游更早。

二、共同原则

使用顺序
板块档位 → 三层判断（基本面、位置、筹码）→ 价格。价格只决定“什么价格做”，不改变“做不做”：等开关板块即使在买入区也不买；任何股票到了卖出参考价，初步意见都改成“不买”。
盈亏比
(卖出参考价−买入区中点)÷(买入区中点−止损价)。低于2说明赚的空间不足亏的两倍，应等更低的买点；这是研究信号，不是硬规则。
现价状态
“在买入区”＝可以按计划执行；“高于买入区X%”＝等回落；“低于买入区（靠近止损）”＝区间可能正在失效，先观察不接；“未确认”＝等开关板块尚未站上60日均线；“已在卖出区”＝持有者兑现，新资金不买。
什么时候重算
每次更新收盘价和一年区间时全部重算；10年国债变化超过0.10个百分点或银行公布新分红时重算银行；板块档位变化时，该板块换用新档位对应的规则。
规则性质
逻辑一的价格规则是研究规则，尚未回测，阈值（0.2、0.4、0.9、12%等）是按板块逻辑设定的初始值，回测后可能调整。逻辑二的买卖规则就是组合回测里用的那一套。
三、输入数据怎么来（一年高低点、60日均线等的换算）
现价
最近一个交易日收盘价（当前为2026-11-13），未复权。
一年高点
现价÷(1+距一年高点回撤)。
一年低点
由“一年区间位置”反推：低点＝(现价−位置×高点)÷(1−位置)。现价就是一年高点时无法反推，该股不给价格。
区间位置
(价格−一年低点)÷(一年高点−一年低点)，0＝一年最低，1＝一年最高。
60日均线
现价÷(1+相对60日线偏离)。
每股分红
2025年度每股分红（与板块页股息率同口径，不用滚动12个月）。
10年国债
1.59%（2026-11-13口径）；变化超过0.10个百分点时重算银行价格。
