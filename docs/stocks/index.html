个股：两条选股逻辑

逻辑一顺着大盘和板块找“风口上最强的船”；逻辑二利用A股制度特点找“有地板、有天花板、偶尔放烟花的房间”。两条逻辑独立筛选，候选名单由我们一起决定。

数据截至2026-11-13 · 本轮只提出候选，不做买卖决定

逻辑一 · 顺势选股

风往哪吹，就在那里找最强的船

来源：大盘风向 → 板块档位 → 板块内的门槛与排序。

赚的是：盈利兑现（分子）与估值修复（分母）。

现在：银行可研究买点；煤炭、石油、油运只做前半段；等开关的方向只观察。

有地板、有天花板，偶尔放烟花

逻辑一：顺势选股

  1. 大盘给出风向表（首页）
  2. 板块分四档：顺风、前半段、等开关、逆风（逆风不选）
  3. 门槛每个板块用自己的硬条件筛（市值、利润、估值）
  4. 排序每个板块一个主排序指标，取前几名

初步意见：顺风与前半段板块的前两名“建议跟踪”，其余“备选”；等开关板块全部“观察，开关前不买”。

逻辑二：国资箱体

把一只股票想成一个房间：地板是国资背景和净资产带来的下限，天花板是没有业绩支撑时游资和散户愿意追到的上限，烟花是政策、重组、题材事件带来的脉冲。

它赚钱的方式不是盈利增长，而是“在地板附近买、在天花板附近卖、遇到烟花就兑现”。

图中“现在”按乐凯胶片当前位置（0.02）画出。

三个动作与一个暂停条件

买：位置在0—0.25（箱底区）

卖：位置≥0.8（箱顶区），或单次脉冲上涨≥30%时兑现

止损：收盘跌破箱底15%，视为箱体失效

暂停条件：中证全指收盘跌破4,700（首页命题P4，托底失效）时不开新仓
现在：中证全指5,120（2026-11-09）→ 规则允许研究买点

这个逻辑过去有没有用

多年滚动检验（2019—2026年，每20个交易日用过去两年数据重算箱体，838只）：箱底信号持有120个交易日平均+4.5%，比同样股票全部时点的平均（+2.6%）高约2个百分点；但中位数只有+0.2%（基准+0.8%），超额来自少数脉冲。效果随年份大起大落。

最近一年单独看：用2024-11至2025-11的箱体，在2025-11至2026-11检验“箱底买、箱顶卖、跌破箱底15%止损、最长持有120个交易日”。箱体股共173次信号，到箱顶37%、止损49%，平均收益-1.1%；同期小盘国资股中位数-22.1%，中证全指-13.9%。箱底区之后60日内跌15%的概率34%，其他位置43%；60日内涨25%的概率15%对19%。

结论：弱而真实的正收益，形状像一组彩票：多数信号横盘到期，少数脉冲贡献收益。“大盘向上才买”的过滤让结果更差，所以不设趋势开关，只在托底失效时暂停。用法应是分散持有多只、单只仓位小。样本按今天的国资标签和市值选取，存在幸存者偏差，真实效果可能更弱；2026年信号整体为负。
