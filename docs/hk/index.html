中国的分子、美国的分母、内地的水龙头：现在两个逆风、一个转暖，判断为先弱后强。

恒指未来半年大概率在22,500—27,000之间。12月美联储会议与1月10日中美关税暂停到期前偏弱；2027年一季度若美联储停止加息，修复速度快于A股。股息率高于港元利率的高息资产先于科技，恒生科技是弹性最大的一块。

为什么重写：港股这一年比A股更难，是因为分母在美国。判断港股，最先要问美联储什么时候停，其次才是中国经济。

分析框架分子、分母、水龙头：指数价格＝企业赚的钱÷投资者要求的回报；中国市场还要看谁在放水、谁在托底。 框架说明：如何用在大盘、板块和个股 →

分子 · 中资企业盈利

预期仍在下修

华泰/FactSet口径下，港股非金融2026年盈利预期近4周下修1.2%，上修公司占比49%（截至11月6日）。11月12日主要平台股继续下跌；AI投入挤压自由现金流的逻辑与美股一致。

推出：互联网平台等盈利修订转正再提高权重。

分母 · 美元利率

仍在变大

恒指PE 13.69倍，盈利收益率7.3%，比美国10年期4.86%只高约2.4个百分点；同口径沪深300约6.0个百分点。恒指股息率2.99%，高于1个月HIBOR 2.59%，高息资产持有收益为正。

推出：港股看起来便宜，但相对它真正的分母并不便宜；高息先于科技。

水龙头 · 南向与供给

南向转暖，供给偏多

截至11月9日南向近20日净卖出361亿港元，但近5日转为净买入，11月12日单日净买入超58亿港元。2026年至5月20日IPO 56宗、募资约1,442亿元，同比翻倍，全年解禁约1.7万亿港元。跨境券商存量内地客户6月起只卖不买，港股部分约600亿港元，分两年出清。

推出：边际买盘在改善，但新增供给会压住估值扩张速度。

什么时候改结论

  1. 日度：只看是否触线；收盘连续3个交易日在线外才改判，单日触线只记录。
  2. 月度：每月15日左右（金融数据公布后）例行复核一次，更新现值，情景概率每次最多调整10个百分点。
  3. 排期事件：事件次日复核，对照事前预期。
  4. 突发事件：归类后观察3个交易日的价格与资金反应；有明确数字的政策（降息幅度、资金规模）可当日评估。
  5. 任何结论变化都要写进更新日志：哪个部件、哪条证据、原结论→新结论。
